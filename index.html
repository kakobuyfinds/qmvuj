What is an ACBuy spreadsheet?

It is a way to organize product links and compare items before ordering through a shopping agent. This independent guide uses listings from CAFANS and lets you export selected rows as a CSV.

What should I check before placing an order?

Confirm that the exact size and color are available. Check the current price and size chart, ask about any unclear measurements, and confirm the return window before paying.

Why can shipping quotes differ for the same parcel?

Shipping lines can differ in how they calculate billable weight and which charges they include. Compare quotes using the same packed dimensions and destination, and check which option includes surcharges or taxes.
